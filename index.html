        How the hybrid AI works
        
      
        
        Every AI call in MinuteMind goes through
        Firebase AI Logic — no other model API is called.
        The app creates one hybrid model with
        getGenerativeModel(ai, { mode: InferenceMode.PREFER_ON_DEVICE, inCloudParams: { model: 'gemini-2.5-flash', generationConfig: { responseMimeType: 'application/json', responseSchema } }, onDeviceParams: { promptOptions: { responseConstraint: schema } } }),
        calls model.initializeDeviceModel() on your click, then
        model.generateContent() — and reads
        result.response.inferenceSource (ON_DEVICE or
        IN_CLOUD) to show which path actually ran.
        Short notes run on Gemini Nano 4 on-device (private, free, works offline);
        long notes fall back to Gemini 2.5 Flash in the cloud. Structured JSON
        output keeps the summary, decisions, action items, and email draft in the same shape
        whichever path ran. Firebase App Check protects the API key; debug tokens are used
        for local development.
      
        
      
        
        MinuteMind is open source (MIT). Your notes are stored only in this browser's
        local storage unless you choose the cloud AI path, in which case the transcript
        is sent to Google's Gemini API via Firebase AI Logic — see the privacy mode above.
